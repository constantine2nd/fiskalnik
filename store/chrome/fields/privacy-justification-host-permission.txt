suf.purs.gov.rs is the Serbian Tax Administration's receipt verification portal. The extension shows its "Додај у календар" (Add to calendar) button on receipt pages there (https://suf.purs.gov.rs/v/...) and reads the receipt when the user clicks it. When the user scans a QR code that contains a receipt link, it downloads that one receipt page from the same site. No other site is accessed.
